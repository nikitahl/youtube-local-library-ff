# YouTube Local Library (Firefox)

A Firefox extension to create and manage YouTube playlists and channels locally (in the browser).

## About

YouTube Local Library lets you save YouTube videos and channels to your local storage, viewable in a separate tab. No YouTube account needed, preserving your privacy while managing your favorite content offline. Simple, secure, and private.

### Features

- Save videos to custom playlists and organize your favorite content exactly the way you want.
- Manage playlists by creating and deleting playlists at any time.
- Save your favorite channels locally and remove them whenever you no longer need them.
- Dark mode support with Light, Dark, and Device Default theme options for a comfortable viewing experience.
- Preserve video information even if a video becomes unavailable or is removed from YouTube. The video title and the channel that uploaded it remain in your library, making it easier to remember and manage your saved content.
- Privacy-first local storage. All playlists, saved videos, and channels are stored only on your device. Your library is never uploaded to YouTube, so Google cannot see or analyze your personal collections.
- No data collection. YouTube Local Library does not collect any user data on its own and does not share any information with third parties.
- No third-party APIs. The extension works independently without relying on external services or APIs, improving reliability, privacy, and long-term compatibility.
- Open source. The complete source code is available on GitHub, allowing anyone to inspect the code, contribute improvements, or verify how the extension works.

### Why use YouTube Local Library?

Unlike YouTube playlists, YouTube Local Library doesn't require signing in or syncing your data to the cloud. Your collections stay on your computer, giving you complete control over your data while providing a fast, lightweight way to organize videos and channels for future reference.

## How to use

- Open YouTube
- Right click on the video/channel link
- Click on the Save to YouTube Local Library option in the context menu
- Select to save video/channel
- Click on the extension icon in browser to open library
- Observe your videos, playlists and channels

## Installing a project

Clone:

```sh
git clone git@github.com:nikitahl/youtube-local-library-ff.git
```

Install packages with yarn:

```sh
yarn install
```

YouTube Local Library uses [Gulp](https://gulpjs.com/) to build JavaScript and CSS files.

Build the project:

```sh
yarn build
```

Watch changes for the project:

```sh
yarn watch
```

Build production version of the project:

```sh
yarn build-prod
```

YouTube Local Library uses [ESLint](https://eslint.org/) to analyze JavaScript code for problems.

Run JavaScript codestyle:

```sh
yarn lint
```
